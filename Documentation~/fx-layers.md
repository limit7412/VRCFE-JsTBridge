# 素体の表情レイヤーの扱い

## 取り除く対象になるレイヤー

FaceEmo より前にあるアバター素体の表情レイヤーは、後ろにいる FaceEmo が上書きするため、FaceEmo を使っている間は意味を持ちません。
FaceEmo は本来、素体の表情レイヤーを削除したうえで使うものです。
ブリッジは FaceEmo を動かしたまま表情を固定するので、フェイストラッキング中もこの上書きは続きます。

ただし、素体のレイヤーのうち Tracking Control の Eyes や Mouth を切り替えるものは、ブリッジの再適用レイヤーと競合します。
こうしたレイヤーが残っているアバターでは、ビルド時に取り除くと競合を避けられます。

## FX Layers To Remove でレイヤーを取り除く

**FX Layers To Remove** にレイヤー名を並べると、ビルド時にそのレイヤーを FX から取り除きます。
アバター素体のアセットは書き換わりません。

どのレイヤーを指定すればよいかは、インスペクタの **除去候補を調べる** ボタンで分かります。
アバターの FX を解析し、競合するレイヤーを根拠つきで挙げます。

- **ブレンドシェイプの重なり**: FaceEmo と Jerry's Templates が書くブレンドシェイプを集め、それと同じものを書くレイヤーを競合とみなします。服のトグルのようにブレンドシェイプを使うだけのレイヤーは候補になりません
- **Tracking Control の切り替え**: Eyes か Mouth を切り替えるレイヤーは、再適用レイヤーと競合します

候補は **追加** ボタンでそのまま一覧へ入ります。
判定はレイヤー名を見ず、書く内容だけで行います。
FaceEmo と同じ名前のレイヤーが素体の FX にあっても、候補から外しません。
アバターによっては、配布時の FX に FaceEmo で作った表情がそのまま焼き込まれています。
焼き込まれた FaceEmo は制御用のパラメータを持たないため、ブリッジでは表情を固定できません。
表情のブレンドシェイプを書くのなら、他のレイヤーと同じく除去の対象です。

除去は名前で行うため、同じ名前のレイヤーは一つの候補にまとまります。
競合しない同名レイヤーがある場合は、追加するとそれも消える旨を候補の欄で断ります。

## 解析と除去の範囲

一覧は網羅ではありません。
Write Defaults が有効なステートは、クリップに書いていないブレンドシェイプも既定値へ戻します。
戻す先にはマージ後に加わる FaceEmo や Jerry's Templates のブレンドシェイプも含まれるため、クリップを読むだけでは分かりません。
候補以外にそうしたレイヤーがある場合は、その旨を出します。

解析するのはアバター自身の FX です。
Merge Animator であとからマージされるレイヤーは除去できないため、対象に含めません。

コンポーネントを複数選択している間は調べられません。
アバターごとに FX が違うため、一つだけ選んでから押してください。

取り除けるのは素体の FX にあるレイヤーだけです。
Merge Animator であとからマージされるレイヤーは対象外で、指定しても見つからない旨の警告が出ます。
