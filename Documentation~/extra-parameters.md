# 追加で書き込むパラメータ

**Extra Parameters** に並べたパラメータは、フェイストラッキングが有効な間だけ別の値になります。
トラッキング中だけ頬染めのトグルを切る、表情パーツのオブジェクトを隠す、といった用途を想定しています。
発動条件は **Bypass Trigger** と同じで、制御方式にかかわらず使えます。

## 書き込むタイミング

フェイストラッキングを有効にしたときにトラッキング中の値を書きます。
無効にしたときの扱いは **解除時** で選びます。

| 解除時 | 動作 |
|---|---|
| 元の値に戻す | 有効にする直前の値へ戻す。既定の設定 |
| 解除時の値を書く | 決まった値を書く |
| 何もしない | トラッキング中の値を残す |

**元の値に戻す** は、有効にした瞬間の値をブリッジのコントローラ内のパラメータへ退避し、無効にしたときに書き戻します。
トラッキング中にメニューで選び直した値は、解除時に退避しておいた値で上書きされます。

アバターを読み込んだ直後は何も書きません。
解除時の書き込みは、そのアバターでフェイストラッキングを一度有効にしたあとに限られます。
読み込みのたびに解除時の値を書くと、保存されているトグルの状態を上書きしてしまうためです。

## 同期するパラメータとしないパラメータ

同期パラメータは装着者のクライアントだけで書き、値は同期でほかの人へ届きます。
書くのは切り替わった瞬間の一度だけなので、トラッキング中でもメニューから選び直せます。

同期しないパラメータは値がほかの人へ届かないため、各クライアントがそれぞれ書きます。
トラッキング中は約1秒ごとに書き直します。
後から入ってきた人のクライアントでは、アバターの読み込み中に書き込みが失われることがあるためです。
書き直すので、トラッキング中にメニューなどで変えた値はすぐに戻ります。

同期の有無は **同期** で選びます。
**自動** は、Expression Parameters、MA Parameters、MA Menu Itemの設定から判定します。
どこにも宣言がないパラメータは、アニメーターだけのパラメータとして同期しない扱いになります。
ほかのツールがビルド中に追加する同期パラメータは判定できないため、**同期する** を選んでください。

## 指定方法

### MA Menu Item

トグルかボタンの MA Menu Item を指定し、トラッキング中の状態を ON か OFF で選びます。
ON はメニューアイテムの値を、OFF は 0 を書きます。
解除時の **解除時の値を書く** は、トラッキング中と反対の状態へ切り替えます。

パラメータ名とトグルの値はビルド時にメニューアイテムから読み取ります。
MA Parameters によるリネームは、内部パラメータも含めて反映します。

パラメータ名が空のメニューアイテムも指定できます。
MA Object Toggle などの Reactive Component を持つメニューアイテムには、Modular Avatar がビルド中にパラメータ名を振ります。
振られる名前はオブジェクトの名前とアバター内のパスから決まるため、ブリッジは同じ名前を組み立てて書き込みます。
Modular Avatar 1.12.0 より前は名前が通し番号で決まり、再現できません。必要環境の下限はこのためです。

次のメニューアイテムは書き込む先を決められないため、NDMF のエラーレポートに警告を出して生成から外します。

- パラメータ名が空で、Reactive Component も持たないもの。Modular Avatar が名前を振らないので、パラメータ自体がありません
- パラメータ名が空のメニューアイテムのうち、Modular Avatar が同じ名前を振るものがほかにもあるもの。同じオブジェクトに複数載っている場合や、同名の兄弟オブジェクトにある場合です。Modular Avatar が 2 つ目以降に付ける枝番を追わないためです
- 値の自動設定が有効で、同じパラメータを使うメニューアイテムがほかにもあるもの。Modular Avatar がビルド中に振る値を求められないためです

いずれも、メニューアイテムにパラメータ名や値を入力すれば使えるようになります。
自動設定が有効でも、パラメータを使うメニューアイテムが 1 つだけなら値を求められます。

### パラメータ名

パラメータ名、型、トラッキング中の値、解除時の値を直接書きます。
MA で作ったもの以外のギミックに使います。
パラメータ名は、Modular Avatar がリネームしたあとの、FX で使われる名前を書いてください。
`FEJsTBridge/Stash/` で始まる名前はブリッジが元の値の退避に使うため、指定すると警告を出して生成から外します。

## 同じパラメータを指す項目

同じパラメータへ書き込む項目が複数ある場合は、先に並んだ項目だけを使い、後の項目は警告を出して生成から外します。
メニューアイテムで指定した項目は、リネーム後の名前で比べます。

## 既知の制限

- 保存されるパラメータは、フェイストラッキングを有効にしたままログアウトすると、トラッキング中の値で保存されます。退避した値は保存されないため、**元の値に戻す** でも防げません
