# 追加で書き込むパラメータ

**Extra Parameters** に並べたパラメータは、フェイストラッキングが有効な間だけ別の値になります。
トラッキング中だけ頬染めのトグルを切る、表情パーツのオブジェクトを隠す、といった用途を想定しています。
発動条件は **Bypass Trigger** と同じで、制御方式にかかわらず使えます。

## 書き込むタイミング

書き込みはトリガーが切り替わった瞬間の一度だけです。
フェイストラッキングを有効にしたときにトラッキング中の値を書き、無効にしたときに解除時の値を書きます。
書き直し続けないので、トラッキング中でもメニューから選び直せます。

アバターを読み込んだ直後は何も書きません。
解除時の値を書くのは、そのアバターでフェイストラッキングを一度有効にしたあとに限られます。
読み込みのたびに解除時の値を書くと、保存されているトグルの状態を上書きしてしまうためです。

書き込みは装着者のクライアントだけで行います。
同期パラメータは値がほかの人へ届きますが、同期しないパラメータはほかの人からは切り替わって見えません。

## 指定方法

### MA Menu Item

トグルかボタンの MA Menu Item を指定し、トラッキング中の状態を ON か OFF で選びます。
ON はメニューアイテムの値を、OFF は 0 を書きます。
解除時の **値を戻す** は、トラッキング中と反対の状態へ切り替えます。

パラメータ名とトグルの値はビルド時にメニューアイテムから読み取ります。
MA Parameters によるリネームは、内部パラメータも含めて反映します。

次のメニューアイテムは書き込む先を決められないため、NDMF のエラーレポートに警告を出して生成から外します。

- パラメータ名が空のもの。Modular Avatar がビルド中に名前を振るためです
- 値の自動設定が有効で、同じパラメータを使うメニューアイテムがほかにもあるもの。Modular Avatar がビルド中に振る値を求められないためです

どちらも、メニューアイテムにパラメータ名や値を入力すれば使えるようになります。
自動設定が有効でも、パラメータを使うメニューアイテムが 1 つだけなら値を求められます。

### パラメータ名

パラメータ名、型、トラッキング中の値、解除時の値を直接書きます。
MA で作ったもの以外のギミックに使います。
パラメータ名は、Modular Avatar がリネームしたあとの、FX で使われる名前を書いてください。

## 既知の制限

- 保存されるパラメータは、フェイストラッキングを有効にしたままログアウトすると、トラッキング中の値で保存されます
- 解除時の **値を戻す** は、トラッキング前の値を覚えて戻すのではなく、決まった値を書きます。トラッキング前に手動で切り替えていた状態は戻りません
